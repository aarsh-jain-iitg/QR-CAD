  • Table rows not aligned with header

Issue 2: Text Wrapping

  • Should truncate with ellipsis on single line

Issue 3: No Way to See Full Filename

  • Poor UX compared to industry standard

Issue 4: Inconsistent Row Heights

  • Professional appearance diminished
  • Alignment issues

Issue 5: CSS Conflicts
  • Duplicate CSS rules causing conflicts
  • Old `.result-row` definitions interfering
  • Duplicate `.rank-simple` styling

================================================================================
                            TECHNICAL DETAILS
================================================================================

Critical CSS Properties:

1. min-width: 0
   Why: Allows flex/grid items to shrink below content size
   Without it: Text overflows instead of truncating
   With it: Text truncates with ellipsis

2. text-overflow: ellipsis
   What: Shows "..." when text is truncated
   Requires: overflow: hidden + white-space: nowrap
   Result: Professional truncation

3. white-space: nowrap
   What: Prevents text from wrapping to new line
   Combined with: text-overflow: ellipsis
   Result: Single-line display

4. title attribute (HTML)
   What: Native browser tooltip
   Shown: On hover over element
   Content: Full filename
   Pattern: Like Windows Explorer, SolidWorks
