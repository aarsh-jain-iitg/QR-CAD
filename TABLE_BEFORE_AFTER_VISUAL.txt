────────────────────────────

.model-name[title] {

TOOLTIP IMPLEMENTATION
================================================================================

HTML (Before):
────────────
<div class="model-name">
    Tray#5_33820540_STEP...
</div>
<!-- No tooltip, user can't see full name -->


HTML (After):
────────────

    Tray#5_33820540_STEP...
</div>
<!-- Hover shows full filename in browser tooltip -->


How It Works:
  1. User hovers over truncated text
  2. Browser detects title attribute
  3. Browser shows tooltip with full text
  4. No CSS needed, no JavaScript needed
  5. Works in all browsers
  6. Matches OS/app styling (Windows Explorer, SolidWorks)
